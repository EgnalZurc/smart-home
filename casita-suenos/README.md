# 🏡 Casita Sueños

Proyecto para encontrar y monitorizar segunda residencia vacacional.
Combina investigación manual de zonas con una app automatizada de alertas de precios.

## Fases del proyecto

| Fase | Nombre | Estado |
|------|--------|--------|
| 0 | Definición de requisitos | ✅ Completada |
| 1 | Definición de posibles localizaciones | 🔄 En curso |
| 2 | Diseño aplicación de precios | ⏳ Pendiente |
| 3 | Desarrollo aplicación de precios | ⏳ Pendiente |
| 4 | Automatización de la app | ⏳ Pendiente |

## Cómo usar este proyecto

El steering con todos los requisitos y perfil económico está en:
`.kiro/steering/casita-suenos.md`

Para cargarlo en una sesión de Kiro: menciona `#casita-suenos` en el chat.

## Estructura

```
casita-suenos/
├── README.md                        # Este fichero
├── fase1-localizaciones/            # Resultados del estudio de zonas
├── fase2-diseno-app/                # Diseño técnico de la app
├── fase3-app/                       # Código de la aplicación
└── fase4-automatizacion/            # Configuración de automatización
```
