## 🎯 Proyecto en Resumen

**Sistema de control inteligente de aire acondicionado** que:

✅ Usa 5 sensores Zigbee repartidos por la casa  
✅ Controla el AC mediante MELCloud API  
✅ Calcula consumo energético y coste en €  
✅ Interface web moderna (PWA)  
✅ Docker para fácil despliegue  

**Estado:** Fase 0 completa (29/30 requerimientos) ✅
