📋 Fase 0: Preparación

  • Backup completo del código
  • Crear tag Git de respaldo
  • Configurar cuenta Docker Hub

⏱️ 30 min

📁 Fase 1: Reestructuración

  • Crear carpeta dashboard/
  • Mover src/backend → dashboard/src/
  • Mover tests → dashboard/tests/
  • Mover servicios → services/
  • Actualizar docker-compose.yml

⏱️ 2-3 horas

🐳 Fase 2: Dockerfiles

  • Crear multi-stage builds
  • Optimizar .dockerignore
  • Objetivo: < 150MB por imagen

⏱️ 1-2 horas

☁️ Fase 3: Docker Hub

  • Crear repositorios por servicio
  • Test de push manual

⏱️ 30 min

🧪 Fase 4: Tests CI

  • Crear workflow test.yml
  • Detectar servicios modificados
  • Configurar notificaciones

⏱️ 1-2 horas

🚀 Fase 5: Deploy CI

  • Configurar secrets en GitHub
  • Crear workflow deploy.yml
  • Crear docker-compose.prod.yml
  • ⭐ Hook Kiro para deploy desde chat

⏱️ 2-3 horas

🔄 Fase 6: Deploy Pi

  • ⚠️ Backup gifts.json (Virchu)
  • Backup todos los datos
  • Cleanup código fuente Pi
  • Deploy desde Docker Hub

⏱️ 2-3 horas

✅ Fase 7: Validación

  • Tests de integración
  • Tests manuales por servicio
  • Verificar datos de Virchu preservados

⏱️ 1-2 horas

📚 Fase 8: Documentación

  • Actualizar READMEs
  • Actualizar steering files locales
  • Limpiar steering de GitHub
  • Añadir .kiro/ a .gitignore
  • Tag post-migration-v1

⏱️ 1 hora

📊 Resumen

Tiempo total estimado: 11-17 horas

Resultado: CI/CD completo con tests automáticos, deploy manual desde GitHub UI o desde Kiro
